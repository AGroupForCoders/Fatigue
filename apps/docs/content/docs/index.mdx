title: Fatigue

Fatigue is a workout tracker for people who lift. It works a lot like Hevy, with two changes we wanted badly enough to build our own app.

## Why we are building it

**Machines are not interchangeable.** 80 kg on a Hammer Strength lat pulldown is not 80 kg on a Technogym one. Most trackers treat them as the same exercise, so your history and records mix two different lifts. In Fatigue you pick the machine brand for an exercise, and history and records are kept per brand.

**Custom exercises should be free.** Hevy limits how many custom exercises you can create without paying. Fatigue does not limit them.

Beyond that, the goal is an app that feels fast. Logging a set should never wait on a network request, because gyms have bad signal.

## Where the project is

The iOS app runs, with logging, routines, history, an exercise page per brand and a Stats tab, and keeps everything in SQLite on the phone. The API signs people in. Sync, Hevy import and the App Store work are still to come, tracked under the [`mvp` label](https://github.com/AGroupForCoders/Fatigue/issues?q=is%3Aissue+is%3Aopen+label%3Amvp). The [MVP](/docs/mvp) page says what is built area by area, and each page below says which parts are decided and which are still open.
