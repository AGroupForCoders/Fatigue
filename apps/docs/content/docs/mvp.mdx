The first version is an iOS app, in light and dark mode, on the App Store, open to anyone. It has to be good enough that we would switch to it from Hevy ourselves. Android and the website come after.

## In the first version

| Area | What you can do |
| --- | --- |
| Logging a workout | Start empty or from a routine, add exercises, log sets, run a rest timer, finish. |
| Machines | Pick the machine for an exercise by brand, with an optional label such as the model or the gym. |
| Custom exercises | Create as many as you like. |
| Flexible sets | Log rep sets and holds, with or without weight, plus your own fields such as a range-of-motion notch. Every set gets a score. |
| Routines | Save a list of exercises and start a workout from it. |
| History | See past workouts, and per exercise see history, records and score for each machine. |
| Account | Sign in with an email and password, with your data backed up and synced. |
| Hevy import | Bring in your existing history from a Hevy CSV export. |

The [requirements](/docs/requirements) page breaks each of these down.

## Not in the first version

- Google and Apple sign-in. They come later and together, because Apple requires its own sign-in whenever Google is offered.
- A social feed, followers and sharing.
- Charts beyond a simple progression line per exercise.
- The [fatigue meter](/docs/fatigue-meter), which shows how tired each muscle is. The first version records the data it needs.
- Apple Watch, HealthKit and a plate calculator.
- Exercise photos, videos or animations.
- The Android app and the website. The database is designed so both can be added without changing it.

We left these out because none of them stop us from using the app day to day, and each one is a sizeable piece of work.

## What the App Store adds

Releasing publicly means Apple reviews the app, and review has rules we have to meet from day one:

- People must be able to delete their account from inside the app.
- The listing needs a privacy policy URL and a completed privacy questionnaire.

## Still open

- **Developer account type.** An individual account is quick to set up but lists a personal name as the seller. An organisation account lists a company name and takes longer. Nobody has decided yet.
