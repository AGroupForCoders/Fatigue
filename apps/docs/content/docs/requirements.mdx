These are the requirements for the [first version](/docs/mvp). They describe behaviour, not screens, so they stay true while the design changes.

## Logging a workout

This is the screen people spend their time on, so it gets the most detail.

- A workout is one scrolling list of exercises. There is no separate "up next" panel.
- You can start a workout empty or from a routine, and add exercises at any point.
- You can reorder exercises by holding an exercise name and dragging it.
- Each exercise has three controls under its name. They are the rest time, a note and the brand.
- By default each set records weight and reps. [What a set records](#what-a-set-records) covers measures, holds, unloaded sets and settings.
- Every set in an exercise has the same boxes under one header row: Previous, the weight if the exercise is weighted, reps or time, each setting typed on every set, RPE and the tick. Add set adds a set like the last one.
- RPE is optional on any set and runs from 6 to 10 in half steps.
- A set can be marked as a warm-up, a drop set or a set to failure by tapping its number. Warm-ups show W in place of a number and never count toward volume, records or scores. Drop sets and sets to failure show D or F but keep their place in the count, so the sets read W, 1, 2, D, 4.
- Each set shows what you did last time on the same brand, so you can see what to beat without leaving the screen.
- Ticking a set as done starts the rest timer for that exercise. You can add or remove 15 seconds, or skip it.
- When rest is over the phone buzzes, whether the workout is open or minimised into the bar above the bottom nav. With the phone locked or the app in the background, a notification says so instead.
- While rest runs, the countdown and the exercise show on the Lock Screen and in the Dynamic Island, with Skip and +15 s, so you can glance at it without unlocking.
- Finishing a workout shows a summary with the time, sets and volume, the records you beat, and a name and description to save it under. Then it goes into your history.
- You can keep up to three photos and videos from your library with a workout, when you finish it or later from its page. They show as a row of thumbnails on the workout's page, and the first one on its row in history. For now they stay on the phone they were added on.
- Each workout can be marked with the gym it was done at, on the finish summary or later from its page. You pick it from the gyms near you or a search on Apple Maps, from the gyms you have used before, or type a name such as "Home" when there is nothing on the map. The finish summary starts with the gym you used last. A gym from the map shows on a small map on the workout's page, and the gym's name shows on its row in history.

## Exercises

- The app ships with a built-in list of exercises, each with a primary muscle and an equipment type.
- If a search finds nothing, the first result offers to create an exercise with the text you typed.
- A custom exercise needs a name, a primary muscle and an equipment type. Secondary muscles are optional. Each exercise records how much of the work each of its muscles does, so a fatigue meter can be added later.
- There is no limit on custom exercises. They are private to your account.
- Custom exercises behave exactly like built-in ones. They get brands, settings, history and records.
- You can delete a custom exercise from Edit exercise. Built-in exercises can't be deleted. Deleting takes it out of the picker and every routine, and never loses logged sets: the confirmation says how many workouts use it, and those workouts keep showing it with their sets.

## Brands

A brand is who made the equipment, such as Technogym or Hammer Strength. "Chest Press" is the exercise. Technogym chest press and Hammer Strength chest press are the same exercise on two brands, and 80 kg on one is not 80 kg on the other.

- A brand is optional. An exercise logged without one, such as barbell squats or dumbbell flies, is on "no brand", which works like any other brand for settings, history and records.
- You create a brand yourself when you want one. Brands come from a built-in list, and you can type your own.
- A brand can have an optional free-text label, for example the model or which gym it is in.
- When you add an exercise to a workout, it defaults to the brand you used last time, or to no brand if you have never picked one.
- Adding a brand to history logged on no brand moves that history to the brand.
- A brand can be renamed, keeping its history, settings and records. Two brands of one exercise can be merged into one, for a typo or for two phones that each added the same brand offline. When both have a setting with the same name the destination's is kept; a setting only the source has comes along.
- History and records are kept per brand. Brands are never shown together, because 80 kg on one machine is not 80 kg on another. The exercise page shows one brand at a time, and you switch between them. [Scores and stats](/docs/scores-and-stats) and [ADR 0001](https://github.com/AGroupForCoders/Fatigue/blob/main/docs/adr/0001-combined-set-score.md) have the reasoning.

## What a set records

Not every set is weight and reps. We want to progress on range of motion and on time as well, so what a set records has to be flexible.

Take the adductors. One set might be 50 kg for 5 reps at notch 4, the next 55 kg for 5 reps at notch 5. A hold at notch 5 for 30 seconds is a different exercise, "Adductors Isometric", with its own history and settings.

- Each exercise has fixed measures: the values every one of its sets records. There are at most three. [ADR 0003](https://github.com/AGroupForCoders/Fatigue/blob/main/docs/adr/0003-per-exercise-measures.md) records why.
  - Reps or time, picked when the exercise is created. It can't change later. A set of an exercise counted in reps is a rep set, and one counted in time is a hold.
  - Weight, or not. An exercise without weight is unloaded, which is not the same as 0 kg and never counts toward a weight record. Weight can be turned on and off later; older sets keep what they had.
  - Any tracked number setting marked "every set", such as "Notch", which then gets a box on every set. It can be turned on and off later; older sets just have no value for it.
- A rep version of an exercise and its held version are separate exercises, such as "Shoulder Press" and "Shoulder Press Isometric", each with its own settings, history and records.
- Built-in exercises come with measures: most are weight and reps, and holds such as Plank, Dead Hang and Wall Sit are time. You can change them like any other exercise.
- A new exercise has no settings. You add them as you go. A setting is a number, such as "Notch", a yes or no, such as "Dead stop", or text, such as "Wide grip".
- A setting that isn't typed on every set has one value for the whole exercise, shown on one line under its name, and filled in from last time. A seat height that never changes costs nothing to keep, and one you are working on shows up in your history.
- Settings belong to the exercise on one brand. Notch 7 on the Technogym adductors means nothing on the Hammer Strength ones, so they do not carry over.
- A number setting can be tracked. You say whether a higher or a lower number is better and give its lowest and highest value, such as notch 1 to 10. The app then detects records on it the same way it does for weight and gives it a line on the graph. Range of motion is almost always a tracked setting.
- A setting can have its own progress for each value. With this on for "Notch", notch 7 and notch 8 each get their own records and their own line on the graph. It is off unless you turn it on, so a seat height that never changes does not split your history.
- The free-text note stays for anything that does not fit a setting.

## Score

Every set gets a score, so one number shows whether you beat last time even when the progress was a deeper notch rather than more weight. [ADR 0001](https://github.com/AGroupForCoders/Fatigue/blob/main/docs/adr/0001-combined-set-score.md) records why.

- The load is weight times reps for a rep set and weight times seconds for a hold. An unloaded set counts its weight as 1.
- Each tracked number setting multiplies the load by a factor from 1.0 at the worst end of its range to 2.0 at the best end. A yes or no setting multiplies by a factor you pick, from 1.0 to 2.0, when it is on. Factors multiply together and the total is capped at 3.0. Text and untracked settings are left out. [ADR 0002](https://github.com/AGroupForCoders/Fatigue/blob/main/docs/adr/0002-settings-weight-the-score.md) records why.
- For example, on a notch 1 to 10 setting where lower is better, 50 kg for 5 reps scores 389 at notch 5 and 417 at notch 4.
- Scores are only compared between sets of the same shape on the same exercise and brand. The shape is whether it is a rep set or a hold, whether it is loaded, and which tracked settings it has a value for. Rep sets and holds are on different exercises, so they are never ranked against each other.
- Adding a tracked setting to an exercise you already have history for starts a new shape. Old sets keep their records and are not compared with the new ones.
- Scores are worked out from the logged values whenever they are shown. Fixing a setting's range or direction recalculates every past score.
- The raw values and their own records are always shown next to the score.

## Routines

- A routine is a named, ordered list of exercises, each with its brand, rest time and planned sets.
- You can create, edit and delete routines.
- Starting a workout from a routine copies it, so changes during the workout do not alter the routine.

## History

- You can see a list of past workouts and open any of them. From there you can fix the sets, rename it, save it as a routine or delete it.
- Each exercise has a page, opened by tapping its name mid-workout or in a past workout. It shows one brand at a time, with a graph, records and every past set.
- The graph plots one thing at a time: set volume, session volume, weight or estimated one-rep max. The two volumes can be weighted by the score or raw. Splitting by a setting draws a line per value, such as notch 7 and notch 8. [Scores and stats](/docs/scores-and-stats) covers the detail.
- During a workout, a set that beats your best for its shape is marked on its row. The exercise page and the finish summary use four records: heaviest weight, best one-rep max, best set volume and best session volume. The finish summary lists the ones you beat.
- A Stats tab shows this week against last, weekly volume for the last 12 weeks, and every exercise you have done with a small trend of its best set volume over the last 8 workouts. Tapping an exercise opens its page.

## Account and sync

- Signing in with an email and password is required before you can use the app.
- If you forget your password, "Forgot password?" emails a link that opens the app to set a new one.
- Signing up sends a verification email. You can use the app before verifying; Settings shows whether the email is verified and can send the email again.
- Everything you log is saved on the phone first, then synced to the server in the background.
- The app works without a connection. Changes made offline sync when the connection returns.
- Signing in on a second device brings down all of your data.
- A workout syncs once it is finished. The running workout stays on the phone it was started on.
- Signing out removes your data from the phone. If something has not been backed up yet, the app says so and asks before signing out.
- Settings shows whether everything is backed up.
- You can delete your account from inside the app, which removes your data from the server.

## Export

- The export icon at the top right of the Profile tab writes every finished workout to one CSV file, `fatigue-export-YYYY-MM-DD.csv`, and opens the share sheet so you can save it to Files, AirDrop it or mail it.
- One row per set. The first columns are Hevy's, with Hevy's names and order, so the file opens anywhere a Hevy export does: `title`, `start_time`, `end_time`, `description`, `exercise_title`, `superset_id`, `exercise_notes`, `set_index`, `set_type`, `weight_kg`, `reps`, `distance_km`, `duration_seconds`, `rpe`. Fatigue has no supersets or distances, so those stay empty, and every set is `normal`.
- Then Fatigue's own columns: `brand`, `brand_label`, `settings` and `weighted_score`. `settings` is the values the set was done with, its own every-set values included, as `Seat=4; Notch=8; Dead stop=yes` in the order they show under the exercise name. `weighted_score` is the [score](#score), rounded to two decimals.
- Dates read like Hevy's, `13 Nov 2025, 07:30`, in the phone's time zone. Unloaded sets leave `weight_kg` empty rather than writing 0.
- Fields with a comma, a quote or a line break are quoted the standard CSV way, and lines end in LF.

## Hevy import

- You can import a Hevy CSV export from Settings. The file is read on the phone and written straight into the local database.
- Each Hevy workout becomes a finished workout with its date, description, exercises, notes and sets. Warm-up, drop and failure sets keep their type. Weights in a pounds export are converted to kilograms.
- Imported exercises are matched to the library by name, ignoring case, punctuation and the equipment in brackets, with a short list of aliases for common Hevy names. Anything unmatched becomes a custom exercise with a guessed muscle, and the import shows you the list afterwards.
- Hevy does not record brands, so imported exercises are on no brand. You can add a brand to them afterwards.
- A workout's id is built from its start time and name, so importing the same file again skips what's already there.

## How it should feel

- Logging a set never waits on the network.
- The app opens straight into your current workout if one is running.
