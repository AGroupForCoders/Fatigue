# Fatigue

A weightlifting tracker that knows which machine you used. History and records are kept per machine brand, and custom exercises are unlimited.

The project is in planning. The only code here so far is the documentation site in `apps/docs`, which covers the MVP, requirements, tech stack, repository layout, API structure and CI plan.

## Read the docs

```bash
pnpm install
pnpm docs:dev
```

Then open http://localhost:3000. You need Node 22 or newer and pnpm.
